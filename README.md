# BuoneNotizie.it — concept redesign

A responsive, static homepage concept for BuoneNotizie.it, built with plain HTML, CSS and JavaScript so it can be deployed directly to GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `buonenotizie-redesign`.
2. Upload `index.html`, `styles.css`, `script.js` and this `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

No Node.js build step is required.

## Before using this as a production website

- This is a front-end concept, not a replacement for the existing WordPress/CMS backend. The article links lead to BuoneNotizie.it's current editorial pages.
- The article selection and copy are illustrative homepage curation based on articles visible on the existing site as of October 2026. Recheck headlines, publication dates and URLs before launch.
- The newsletter form is intentionally a visual/front-end placeholder. Connect it to the publisher's approved newsletter provider before collecting addresses; it does not submit or store personal data.
- The search feature searches the small set of articles included in this prototype. For a full-site search, connect the CMS or a search service.
- The photos are externally hosted Unsplash image URLs used as design placeholders. Replace them with BuoneNotizie's owned/licensed editorial images and keep the relevant image credits before production.
- Confirm the right to use the BuoneNotizie name, logo and editorial assets before publishing a public-facing version. This is an independent redesign proposal.

## Design direction

Warm editorial paper background, deep forest green, muted sage and terracotta accents, serif headlines, clear content hierarchy, responsive navigation, featured journalism, topic discovery, positive stories, video and newsletter sections.
